# 영어 레벨업

혼자 쓰는 영어 말하기 연습 앱입니다. Claude 아티팩트로 열어서 씁니다.

- **오늘의 미션**: 쓰기(순간영작) 15문장, 듣고 말하기 15문장, 오답 복습 3문장. 연습 한 세트도 15문제
- **연습**: 순간영작, 따라 말하기, 듣고 대답하기
- **레벨 테스트**: 15문항(쓰기 5, 듣기 5, 말하기 5). 세 영역 모두 70점 이상이면 합격해서 레벨이 오릅니다. A1~C1 중 원하는 레벨을 언제든 볼 수 있습니다. 같은 레벨을 다시 볼 때는 Claude가 그 레벨에 맞춰 새 문제를 자동으로 만듭니다.
- **오답노트**: 틀린 문장 모음, 문장마다 Claude에게 질문하기
- **설정**: 레벨 직접 정하기, 미국/영국 발음, 듣기 속도

문제는 CEFR 기준과 공인 말하기 시험(토익스피킹, OPIc, 캠브리지)의 문제 유형을 따랐습니다. 연습용 판정이며 공식 성적은 아닙니다.

## 채점과 기록

로그인한 Claude 계정으로 채점하므로 API 키와 추가 요금이 없습니다. 기록은 내 Claude 계정에 나만 볼 수 있게 저장됩니다. 아티팩트 안에서는 마이크를 쓸 수 없어서 말하기는 키보드 받아쓰기로 입력합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `artifact/english-levelup.html` | 아티팩트로 올리는 완성 파일 (직접 고치지 말고 다시 만들기) |
| `artifact/app.js` | 화면과 동작 |
| `artifact/ai-sample.js` | Claude 채점, 문제 생성, 질문 답변 |
| `bank.js` | 레벨별 문제 은행 |
| `speech.js` | 영어 음성 재생 |
| `styles.css` | 화면 스타일 |
| `artifact/build.py` | 위 파일을 하나로 합치는 스크립트 |

다시 만들기: 저장소 루트에서 `python3 artifact/build.py . artifact artifact/english-levelup.html`
