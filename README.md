# 영어 레벨업 · 꼬리물기 영어

혼자 쓰는 영어 말하기 연습 앱입니다. Claude 아티팩트로 열어서 씁니다.

Claude가 질문 하나로 대화를 시작하고, 내 대답에서 꼬리를 물어 계속 질문합니다. 주제는 Claude가 고르고, 최근에 한 주제는 피합니다.

- **대화**: 대답할 때마다 틀린 표현을 한 줄로 고쳐 주고 바로 다음 질문으로 이어 갑니다. 질문마다 듣기와 한국어 뜻 보기, 막히면 힌트(답변 예시)나 "모르겠어요"를 쓸 수 있습니다. 중간에 나가도 대화가 저장돼서 이어 할 수 있습니다.
- **기록**: 끝낸 대화를 주제별로 다시 봅니다.
- **오답노트**: 대화에서 고친 문장 모음, 문장마다 Claude에게 질문하기
- **설정**: 레벨(A1~C1, 질문의 어휘와 길이가 달라짐), 미국/영국 발음, 듣기 속도

하루 목표는 대답 15개입니다.

## 채점과 기록

로그인한 Claude 계정으로 대화하므로 API 키와 추가 요금이 없습니다. 기록은 내 Claude 계정에 나만 볼 수 있게 저장됩니다. 아티팩트 안에서는 마이크를 쓸 수 없어서, 키보드를 English로 바꾸고 키보드 받아쓰기로 입력합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `artifact/english-levelup.html` | 아티팩트로 올리는 완성 파일 (직접 고치지 말고 다시 만들기) |
| `artifact/app.js` | 화면과 동작 |
| `artifact/ai-sample.js` | Claude 대화, 교정, 질문 답변 |
| `speech.js` | 영어 음성 재생 |
| `styles.css` | 화면 스타일 |
| `artifact/build.py` | 위 파일을 하나로 합치는 스크립트 |

다시 만들기: 저장소 루트에서 `python3 artifact/build.py . artifact artifact/english-levelup.html`
